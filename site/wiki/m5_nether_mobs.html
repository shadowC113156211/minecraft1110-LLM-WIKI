下界生物應對：要塞、堡壘與各種怪物

學習目標｜認識下界主要生物與兩大結構（下界要塞、堡壘遺跡），知道該打誰、該躲誰。

下界兩大結構

• 下界要塞：深色磚塊組成的長走廊與橋。有烈焰使者（掉烈焰桿）、凋零骷髏，以及長在靈魂砂上的地獄疙瘩。→ 中後期的必去地點。
• 堡壘遺跡：黑石建成的大型建築，住著豬布林與豬布林蠻兵，寶箱有金塊、獄髓升級模板。→ 危險，建議裝備充足再去。

怪物對照表

• 地獄幽靈：遠程火球 → 把火球打回去、弓箭。
• 烈焰使者：火球＋近戰 → 抗火藥水、利用掩體。
• 凋零骷髏：凋零效果 → 躲進 2 格高的通道、帶牛奶。
• 岩漿立方怪：跳躍分裂 → 高處、弓箭。
• 豬布林：穿金甲就安全，別開箱子挖金。
• 豬布林蠻兵：無視金甲 → 弓箭＋窄道。
• 殭屍化豬布林：中立但群起報復 → 不要打。
• 疣豬獸：衝撞頂飛 → 盾牌、遠離岩漿邊。
• 終界使者：在扭曲森林很多 → 別直視。

怎麼找下界要塞？

下界要塞通常沿著南北（Z 軸）方向分布成帶狀。從傳送門出發，沿 X 軸方向（東西）筆直前進，最容易橫切到要塞。開闊處登高遠望，深紅色磚塊就是要塞。

過關清單（勾選會記在這台電腦）

  • 7+ 根烈焰桿
  • 一些地獄疙瘩與靈魂砂
  • 安全回到傳送門
